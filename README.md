# Hymn Keeper

Créer une application Android 

RECUEIL DES CHANTS TESP. Cette application va enregistrer les cantiques (numéro cantique, Nom cantique,  texte cantique). La liste des cantiques sera affichée. lorsqu'on sélectionne un nom cantique, on affiche le texte cantique dans une autre fenêtre. L'application aura un menu déroulant à gauche qui aura aussi comme menu : Accueil, aide, Notre chaine youtube, paramètres, Livre du conducteur,  à propos et quitter



- Menu accueil : l'accueil de l'application 

- Menu aide : explique aux utilisateurs comment utiliser l'application pour afficher le texte cantique 

- Menu notre chaîne youtube : renvoie l'utilisateur sur le lien : https://www.youtube.com/@TabEsperance

- menu Paramètres : affiche les paramètres de l'application (modifier la police, contacter l'administrateur sur whatsapp,  Gmail)
